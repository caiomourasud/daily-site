# daily-site

Site do **Daily** — publicado em
https://caiomourasud.github.io/daily-site/

Gerado por `tool/build_site.dart` no repo `caiomourasud/daily` (privado), a
partir de `site/` e dos documentos em `assets/legal/`. Este repo é
sobrescrito (force-push) a cada publicação; **não edite nada aqui** — a
alteração se perde na próxima.

Os termos e a política vivem aqui e **não** dentro do app: é o que a App Store
e a Play Store pedem, e mantém um texto com um renderizador só.
